Hướng dẫn Google Drive — cấu hình và nhiều tài khoản

Bật Google Drive API chưa đủ để đăng nhập. Cần tạo cấu hình OAuth, nhập file JSON vào phần mềm, rồi mới đăng nhập. Cấu hình OAuth dành cho ứng dụng; mỗi người vẫn dùng tài khoản Google riêng.

1. Thiết lập Google Cloud lần đầu
  1. Mở , đăng nhập và chọn dự án ở thanh trên cùng.
  2. Vào APIs & Services → Library, tìm Google Drive API → Enable. Nếu đã thấy Enabled hoặc Disable API thì bước này đã xong.
  3. Bấm OAuth consent screen ở menu trái. Google có thể chuyển sang Google Auth Platform. Nếu chưa cấu hình, bấm Get started.
  4. Trong Branding / App information, nhập tên ứng dụng, email hỗ trợ và email liên hệ. Trong Audience, chọn External để dùng Gmail và tài khoản ngoài tổ chức; Internal chỉ dành cho tổ chức Workspace. Hoàn tất thông tin rồi bấm Create / Save.
  5. Nếu ứng dụng đang Testing: vào Audience → Test users → Add users, thêm email của bạn và từng người muốn đăng nhập, rồi Save.
  6. Trong Data Access → Add or remove scopes, khai báo quyền openid, userinfo.email, userinfo.profile và https://www.googleapis.com/auth/drive.metadata.readonly. Phần mềm dùng quyền đọc danh sách và thông tin tài liệu để lấy link.
2. Tạo file JSON và nhập vào phần mềm
  1. Vào Google Auth Platform → Clients → Create client. Với giao diện cũ: APIs & Services → Credentials → Create credentials → OAuth client ID.
  2. Chọn Application type: Desktop app, đặt tên, bấm Create. Phần mềm hiện tại cần đúng loại Desktop app.
  3. Tải Download JSON của client vừa tạo và lưu file trên máy. Đây là file cấu hình OAuth, khác với API key hoặc file service account.
  4. Quay về Cài đặt → Quản lý Link → Cấu hình OAuth Google, chọn file JSON. Đợi thông báo đã lưu cấu hình.
  5. Bấm Đăng nhập / Thêm tài khoản Google, chọn tài khoản trong trình duyệt và cấp quyền. Trở lại phần mềm: email phải xuất hiện trong danh sách tài khoản.
3. Người khác hoặc tài khoản khác muốn dùng Drive

Cùng một cấu hình ứng dụng có thể dùng nhiều tài khoản. Khi còn Testing, người quản lý dự án Google Cloud thêm email mới vào Test users trước. Người dùng bấm Đăng nhập / Thêm tài khoản Google → Use another account và tự xác thực. Không cần tạo dự án Cloud mới cho từng email.

Trên máy khác, nhập cấu hình OAuth do người quản lý cung cấp rồi đăng nhập tài khoản của người dùng đó. Mỗi tài khoản chỉ lấy được tài liệu mà nó có quyền truy cập.

Chọn một email hoặc Tất cả tài khoản → Lấy toàn bộ link tài liệu. Phần mềm gộp tài liệu trùng. Bấm × cạnh email để ngắt kết nối tại máy này; các link đã lưu vẫn được giữ.

4. Khi đăng nhập hoặc lấy link bị lỗi
  • 401 / invalid_client: nhập lại JSON của OAuth Desktop client hiện hành. Bật API hoặc thử lại Gmail không thay thế cấu hình sai.
  • 403 / access_denied: kiểm tra email có trong Test users, lựa chọn External / Internal và chính sách của tổ chức.
  • API chưa bật: bật Drive API trong đúng dự án đã tạo OAuth client.
  • Phiên hết hạn: đăng nhập lại. Khi dùng Testing với quyền Drive, Google có thể giới hạn refresh token trong 7 ngày.
  • Thiếu tài liệu: kiểm tra quyền chia sẻ trên Drive bằng đúng email đã chọn, rồi lấy link lại.
